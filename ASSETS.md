# Data and Asset Manifest

`results/` and `paper/` are produced by this project and offered under ASL-1.1 as Project Data.
`phenomenology/data/` holds published measurements transcribed with their source on every row;
the values are facts from the cited publications, not AegeanWorks material, and keep the terms of
those sources. No personal data and no model weights ship.

| Path or pattern | Type | Rights holder | License | Personal data | Notes |
|---|---|---|---|---|---|
| `results/` | simulation outputs | AegeanWorks | ASL-1.1 | no | regenerated by `make results` |
| `paper/` | manuscript sources | AegeanWorks | ASL-1.1 | no | original |
| `phenomenology/data/pdg2024_leptons.csv` | lepton masses | Particle Data Group | cite PDG 2024 | no | PRD 110 030001 |
| `phenomenology/data/nufit52_neutrinos.csv` | neutrino oscillation fit | NuFIT collaboration | cite NuFIT 5.2 | no | nu-fit.org |
| `phenomenology/data/quark_masses_hz2021.csv` | running quark masses | Huang & Zhou | cite PRD 103 016010 | no | Table II |
